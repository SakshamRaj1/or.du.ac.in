📖 About the Project

This is a website design project created for the Department of Operational Research at the University of Delhi. It aims to present departmental information through a clean, modern, and accessible university-style web interface.

The project provides a multi-page website structure for organizing academic information, admissions, faculty and administration details, research activities, alumni information, opportunities, and departmental updates.

Built primarily with HTML, CSS, and JavaScript, the project serves as a front-end website template that can be explored, customized, and extended for academic or institutional use.

Note: This repository is an independently developed website concept. It should not be considered the official website or an official communication channel of the University of Delhi.

✨ Features
Modern UI: A contemporary website layout inspired by university and academic portals.
Multi-page structure: Separate pages for different departmental sections.
Academic information: Dedicated sections for academics and admissions.
People and administration: Pages for departmental personnel and administrative information.
Research and innovation: A dedicated section for research-related content.
Alumni and opportunities: Pages for alumni information and academic or professional opportunities.
Reusable components: Separate header and footer files for organizing shared website elements.
Media assets: Organized image and GIF directories for website visuals.
Front-end customization: HTML, CSS, and JavaScript files that can be modified to suit different requirements.
GitHub Pages hosting: A publicly accessible deployment for previewing the website.

🚀 Getting Started

You can run the website locally using any modern web browser.

Prerequisites
Git
A modern web browser such as Chrome, Firefox, Edge, or Safari
A code editor such as Visual Studio Code (recommended)
1. Clone the Repository
bash
git clone https://github.com/SakshamRaj1/or.du.ac.in.git

2. Navigate to the Project Directory
bash
cd or.du.ac.in

3. Open the Website

Open index.html directly in your browser.

Alternatively, use the Live Server extension in Visual Studio Code to serve the website locally. This is preferable if the project uses relative paths, shared HTML components, or browser features that require an HTTP server.

4. Explore and Customize

Open the project in your preferred editor and modify the relevant HTML, CSS, JavaScript, or supporting files.

For example:

Update page content in the corresponding .html file.
Modify visual styles in the style/ directory.
Update client-side behavior in the js/ directory.
Replace or add website visuals in the img/ and gif/ directories.

No package installation is required for basic static HTML previewing. Additional dependencies may be needed if individual scripts or development workflows require them.

🔧 Development and Customization

If you want to build on this project, consider the following workflow:

**Flask backend Enthusiants are welcomed!!**

Understand the existing structure: Review the HTML pages and their linked stylesheets, scripts, and assets.
Keep components consistent: Maintain a consistent navigation structure and footer across the website.
Improve responsiveness: Test layouts on mobile, tablet, and desktop screen sizes.
Check accessibility: Use semantic HTML, descriptive image alt text, readable color contrast, and keyboard-friendly navigation.
Optimize performance: Compress large images and GIFs, remove unused styles, and avoid unnecessary JavaScript.
Validate links: Ensure internal navigation and asset paths work both locally and after deployment.
Test before publishing: Preview the website in multiple browsers and screen sizes before merging changes.
